# Add trigger function to react from talweg_metrics insert or delete.

Add trigger function to react from talweg_metrics insert or delete.

## Usage

``` r
fct_talweg_metrics_insert_delete_reaction(
  db_con,
  table_name = "talweg_metrics"
)
```

## Arguments

- db_con:

  DBI connection to database.

- table_name:

  table name.

## Value

text
