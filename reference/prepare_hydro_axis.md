# Prepare hydrologic axis dataset to database export.

Prepare hydrologic axis dataset to database export.

## Usage

``` r
prepare_hydro_axis(
  referentiel_hydro_dataset = input_referentiel_hydro,
  hydro_swaths_dataset = hydro_swaths
)
```

## Arguments

- referentiel_hydro_dataset:

  sf data.frame hydro_axis dataset.

- hydro_swaths_dataset:

  sf data.frame hydro_swaths dataset prepared.

## Value

sf data.frame
