# Add trigger function to react from continuity_area insert or delete.

Add trigger function to react from continuity_area insert or delete.

## Usage

``` r
fct_continuity_area_insert_delete_reaction(
  db_con,
  table_name = "continuity_area"
)
```

## Arguments

- db_con:

  DBI connection to database.

- table_name:

  table name.

## Value

text
