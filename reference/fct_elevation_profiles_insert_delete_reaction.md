Add trigger function to react from elevation_profiles insert or delete.

## Usage

``` r
fct_elevation_profiles_insert_delete_reaction(
  db_con,
  table_name = "elevation_profiles"
```

## Arguments

- db_con:

  DBI connection to database.

  table name.
